## Выдача

Сначала установить APK0.8.0, затем Settings → Импорт / Восстановление → обновлённый ZIP. Это полное восстановление присланного снимка, не слияние с более поздними покупками телефона. Оригинальный файл сохранён. Личная база не упакована в APK; проверочные fixtures относятся только к тестовым исходникам. Безcommit/push/PR и установки телефона.

Выбор адреса BranchChoiceField следует тому же порядку: реальные адреса, «По приоритету для каждого товара», «Без конкретного адреса», «Новый адрес…». Проверены порядок и различия ID конкретной точки/нулевого адреса наAPI28/35.

При быстром создании магазина AddToListViewModel блокирует подтверждение покупки до завершения операции, сохраняет созданный ID как явный выбор; запоздавшая эмиссия списка не переводит его в AUTO. Доступность явного ID проверяется репозиторием при записи. Старый UI-тест теперь ждёт закрытия inline-редактора, а не совпадения с набранным именем.
