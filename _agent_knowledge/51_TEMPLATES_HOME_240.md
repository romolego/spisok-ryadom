# Главная, быстрое избранное и шаблоны ·0.24

Прямой запрос21 октября2026 снимает прежнее ожидание следующего пакета. Одна итерация: явный активный фильтр избранного, фактическая отметка добавления в быстром выборе, название вкладки «Главная», многоразовые шаблоны в разделе списков. Версия0.24.0(code32), Room21/ZIP18. Окончательные результаты —01; промежуточные прогоны не считаются итоговыми.

## Фильтр и быстрый выбор

Каталог с favorites_only=true показывает явную цветную плашку «Только избранные» с действием «Показать все». Звезда — переключатель со значением checked для доступности. Скрытие товаров фильтром не меняет каталог. История21 октября: все товары уже находились в экспорте; пропажа была визуальной.

В AddToListViewModel pendingProductLabels строится из реальных видимых некупленных строк ShoppingListRepository, включая строки обычных целевых списков с showInPurchases. Заготовки шаблонов сюда не входят. Количества суммируются отдельно для каждой канонической единицы, без сложения разных единиц. Обе копии избранного товара и результаты поиска показывают «В списке» с количеством, значком и анимацией появления/фона. Быстрое действие после добавления называется «Добавить ещё». Избранность не снимается, строки не исчезают; купленные/удалённые покупки снимают отметку реактивно. Статус сохраняется при повторном открытии, поскольку это не локальная память клика.

## Шаблон и обычный список

GoalListEntity.isTemplate=false означает прежний целевой список. isTemplate=true — многоразовая заготовка, всегда showInPurchases=false, без купленных строк. Отдельной параллельной таблицы товаров/количеств нет: заготовки используют существующие поля покупок с владельцем-listId. Отрицательные/особые listId для типа не используются.

В разделе «Списки» обычные списки и шаблоны находятся в двух отдельных секциях. Создание использует общий диалог имени с типом. Из текущих покупок шаблон сохраняется кнопкой копирования в первой карточке раздела; отдельный список — действием «Сохранить как шаблон». Источник не перемещается. При сохранении из текущих покупок берутся все строки общего агрегата, включая купленные и видимые целевые списки; отметки купленного сбрасываются. Это позволяет сохранить заготовку после завершения закупки.

Редактор шаблона использует тот же ввод/каталог/единицы/цены/места, но скрывает управление купленным и обычную видимость на Главной. Выделение позволяет удалить позиции; перемещение заготовок как покупок не предлагается и запрещено репозиторием. Шаблон применяется кнопкой в карточке раздела или в собственном редакторе.

## Применение

TemplateApplySheet — единое подтверждение назначения: Главная, новый обычный список либо существующий обычный список. Шаблоны не являются назначением. На Главную записываются регулярные покупки с listId=null, поэтому используются прежние действия, группировка и источник данных виджета. Предупреждение до подтверждения явно сообщает число всех позиций и влияние на Главную/виджет; простое открытие окна ничего не записывает. Новый отдельный список скрыт с Главной, пока пользователь явно не включит показ.

GoalListRepository.applyTemplate выполняет всю операцию одной Room-транзакцией: проверяет тип источника/назначение/непустоту и версии строк, при необходимости создаёт список и копирует все позиции. UI выполняет команду через withSession/generation; busy блокирует повтор одного нажатия. Поменявшаяся за время подтверждения заготовка требует повторного просмотра. Ошибка, включая переполнение суммарного количества, откатывает список, покупки и временные товары целиком.

У копий новые ID и даты, isBought=false; единицы, количества, ориентировочная цена, срочность, заметка/комментарий и место сохраняются. Постоянные товары остаются ссылками на каталог. Временные товары клонируются с новыми stableId, чтобы редактирование/удаление копии не меняло заготовку или другой список. Повторное применение — намеренное новое добавление: совместимые каталожные покупки суммируются общим addOrMergeEntry, быстрые текстовые позиции независимы. Заготовка не расходуется. Показ обычного списка на Главной по-прежнему НЕ копирует строки; копирование относится только к применению/сохранению шаблона.

## Совместимость и границы

MIGRATION_20_21 добавляет isTemplate=0, сохраняя все прежние сущности, ID, связи и купленную историю. Цепочки миграций и pre-upgrade recovery обновлены до21. Предыдущие схемы сохранены.

ZIP18 хранит строгий булев isTemplate; старые поддерживаемые ZIP без него восстанавливаются как обычные списки. Поддельные старые версии с настоящими шаблонами и недопустимые состояния «шаблон показан в покупках/куплен» отклоняются до замены базы. Полный импорт по-прежнему замещает снимок, не выполняет слияние. Отдельный текстовый/JSON экспорт шаблона использует v3 с типом; обычные документы сохраняют v1/v2. Импорт шаблона создаёт скрытую многоразовую заготовку с некупленными позициями и текстовыми местами без доверия чужим ID.

Все SELECT/очистки основного агрегата явно исключают isTemplate. Widget check дополнительно проверяет тип владельца. Жизненный цикл временных товаров/медиа и ResetRepository работают с теми же владельцами; удаление шаблона не удаляет его ранее применённые независимые копии. Макет/настройки виджета не перерабатываются.
