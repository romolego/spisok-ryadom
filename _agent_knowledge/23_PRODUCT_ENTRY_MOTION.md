- Плавная перестановка обеих соседних строк во всех местах со стрелками: магазины, корзина, адреса, группы магазина, привязки товара и справочники. Убрана принудительная прокрутка; при явной перестановке фиксируется положение viewport.
- Группу магазина можно создать непосредственно при привязке к товару или смене его группы. Это черновик: товар, новые используемые группы и ограничения точек сохраняются одной транзакцией. Отмена не оставляет случайных групп.
- При привязке сети можно сразу выбрать точки продажи. Переключатель появляется только при нескольких адресах; позднее доступность можно изменить в карточке. Проверен выбор третьего и пятого адресов из пяти.
- Ручной порядок товарных групп сохраняется и используется в выборе/группировках. Доступен в настройках и по значку сортировки в карточке товара. Новая группа добавляется в конец приоритетов.
- Результаты быстрого поиска размещены сразу под названием и видны при открытой клавиатуре. Одноимённые товары показывают магазины, единицу/количество и заметку. Выбор использует конкретный ID; прежние дубли не объединяются автоматически.
- Фото товара можно выбрать из галереи или снять камерой из приложения. Приватный FileProvider, импорт/сжатие, preview и блокировка Save во время обработки общие для товаров и точек. Отмена повторной съёмки сохраняет прежнее фото.
- Повторное использование существующего товара сохраняет его прежние данные и связи; новые связи получают выбранную группу и адреса.

## Ключевые детали

AnimatedOrderColumn хранит движение по ID и выполняет покадровое чтение только в placement. В LazyColumn — animateItem с tween300 и ReorderViewport; обычное обновление данных не запускает принудительный scroll. Передают ID для магазинов/групп/связей/адресов. Быстрый reverse идёт от текущей позиции. Поля адресов/групп перед движением освобождают фокус, чтобы клавиатура не перетягивала прокрутку.

Новые группы магазина существуют в ProductCardUiState.pendingDepartments до Save. Отрицательные ID разрешаются в реальной транзакции, сохраняются только группы, используемые итоговыми связями. Совпавшее нормализованное имя в том же магазине переиспользуется. Ошибка чужой/пустой доступности откатывает товар и группу. Reuse товара сохраняет прежние ID/приоритеты/поля и переносит новые группы/точки только в новые связи.

При выборе магазина показывается BranchAvailabilityEditor с той же Map shopId→Set branchId, что в карточке. Для одной точки переключатель не рисуется, существующее ограничение при этом не стирается. Адреса отсортированы по приоритету, выбранная доступность используется автоподбором корзины. Проверен набор3/5 из пяти, первая покупка назначается в3.

ProductGroupDao уже читал displayOrder; управление теперь открывается и из карточки товара. Создание новой группы использует max+1. Настройки/каталог/корзина и выбор карточки используют один порядок.

Быстрое добавление: query→candidates→shop/quantity/action. При выборе остаётся одна карточка; долгие метаданные ограничены двумя строками. Общий ProductContext строится из потоков, без SQL-запросов в каждой строке. Нечёткий поиск прежний, при обновлении выдачи сохраняет старые строки с индикатором, выбор блокируется до завершения поиска. Старые дубли сохраняются, карточки показывают происхождение.

BranchPhotoEditor общий для товара/точки: GetContent/TakePicture, FileProvider cache/camera_captures, PhotoStore IO с EXIF/JPEG1600. Товар сохраняется в product_photos; busy блокирует Save и повторное использование, отмена камеры не сбрасывает старое фото. Внешняя камера не требует собственной формы съёмки или CAMERA permission.
