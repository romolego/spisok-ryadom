# Настройки и сброс ·0.21.0

Требования текущей итерации пользователя имеют приоритет над прежним общим оформлением0.20. Room18 без миграции; полный backup ZIP15, чтение прежних версий сохраняется.

## Оформление избранного

В настройках одна компактная строка «Оформление избранного» открывает модальное окно. Контексты: «Покупки» — главный экран; «Списки» — целевые списки, каталог, подбор и обычные справочники; «Выпадающие списки» — селекторы и массовый выбор групп. В каждом контексте верхний блок избранного и повторные строки в полном перечне имеют независимые фон/цвет/звёздочку/жирность. Управление иконками с accessibility-подписями; цвет выбирается существующим HSV-полем/HEX. Данные и порядок избранного не изменяются.

`FavoriteAppearance` сохраняет старые block/row ключи для обычных списков. Новые purchases_block/row и dropdowns_block/row при отсутствии читаются из прежних block/row: обновление не меняет внешний вид самостоятельно. После первого сохранения все шесть стилей независимы. Новые ключи валидируются при импорте до записи базы.

## Новые товары

Количество и единица находятся рядом под переключателем «Подставлять, если не заполнено». На новой установке выключено: пустые поля карточки сохраняются пустыми. Ранее сохранённая единица/количество включает совместимое поведение, пока пользователь явно не отключит его. Введённые значения не заменяются. Тип покупки находится в отдельном блоке. Количество фактической покупки по-прежнему положительно: без ввода одна покупка, даже если nullable defaultQuantity карточки не задано.

## Сброс

`ResetRepository` в AppContainer; блокировка media → editor, NonCancellable после старта, Room-транзакция, согласование raw-черновиков. В UI выбор режима и отдельное подтверждение с точным перечнем последствий. На время команды блокируется взаимодействие с настройками.

- «Восстановить готовые группы»: восстановить узнаваемые встроенные группы (каноническое имя либо известный alias), значки/оформление/избранность; добавить недостающие. Сохраняются ID, пользовательские группы, товары, покупки, связи и локальный маршрут отделов. Полностью переименованная пользователем группа без известного alias считается пользовательской: происхождение в модели не хранится, поэтому она сохраняется.
- «Только исходные выпадающие списки»: удалить пользовательские группы/получателей/единицы, отделы магазинов и ссылки на них; установить30+30 встроенных групп. Товары, магазины, целевые списки, покупки, количества/единицы и цены сохраняются. Единицы в товарах/покупках — строки, они не стираются удалением справочника. Исходная установка не создаёт получателей или единицы.
- «Сбросить всё приложение»: удалить все пользовательские таблицы, локальные настройки, raw-черновики, фото/логотипы, внутренние recovery/backup/share-файлы; создать город «Мой город» и30+30 групп как при первом запуске. Файлы вне приложения не затрагиваются. Не сбрасывать sequence ради повторного использования старых ID. Сначала успешный commit базы, затем prefs/внутренние файлы. Внешняя файловая система не является частью SQLite-транзакции: ошибка очистки показывается пользователю.

После сброса справочников или приложения меняются поколение редакторов и локальная revision. Старые открытые редакторы не могут вернуть удалённые ссылки или записать данные по прежним ID. Полный сброс пересоздаёт навигацию с экрана покупок. Восстановление готовых групп использует синхронизатор без смены поколения.

## Использование справочников

Нажатие получателя/товарной группы/единицы показывает алфавитный список товаров; строка закрывает окно и открывает настоящую карточку через NavGraph. Группа магазина показывает магазины с товарами под каждым; кликабельны магазин и товар, пустые размещения обозначены отдельно. Для старых данных учитываются читаемые исключения отдела по точкам; новый UI их не создаёт. Названия павильонов отображаются через общий PlaceLabels.

## Виджет

Удалены только текстовый образец размера и кнопка «Обычный размер» в настройках. Ползунок и числовое значение сохранены. Код RemoteViews/службы/провайдера, группировки и действия виджета не изменяются.
