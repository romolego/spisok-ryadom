# Магазины, точки, единицы и фон ·0.22.0

Итерация по запросу пользователя: убрать неуместный переключатель порядка, сохранять все варианты единиц при вводе, проверить сеть с точками в нескольких ТЦ и на улице, согласовать обычный значок магазина, удержать действия окна групп в экране и добавить фон карточек внутри подложки магазина.

## Магазин, сеть, ТЦ

Существующая модель сохраняется: ShopEntity — профиль магазина в городе; RetailNetworkEntity — необязательная сеть; ShopBranchEntity — точка, у которой независимо задан venueId. Один профиль может одновременно содержать точку вТЦ1, вТЦ2 и отдельный уличный адрес. Назначение ТЦ одной точке не назначает его всему профилю и не меняет сеть. Для такого сценария не нужно преобразовывать магазин в рынок/ТЦ: преобразование — отдельная подтверждаемая операция для самостоятельных продавцов.

ShopPlaceSummary показывает сеть и каждую точку со своим ТЦ либо «Отдельный адрес». ShopListViewModel уже показывает тот же профиль под соответствующими ТЦ и в обычном перечне для уличных точек, сохраняя один ID. Новое исправление: ShopContentViewModel называл секции голым адресом; теперь использует PlaceLabels.branch и наблюдает изменения названий ТЦ. ProductOutletOptions также показывает контекст ТЦ при выборе доступности/приоритета. Общее имя профиля со смешанными точками не получает ошибочный префикс одного ТЦ.

По-прежнему не дублировать строки покупок ради отображения и не преобразовывать сеть в контейнер автоматически. Режим «Во всех точках» оставляет общую секцию товаров, если нет локальных маршрутов; секции конкретных адресов заполняются при ограниченной доступности/маршрутах. Все адреса видны в карточке магазина независимо от наличия товаров. Удаление ТЦ снимает только его venue-ссылки, сеть и покупки сохраняются. Чужой город отклоняется транзакционно.

## Карточка товара и единицы

«Свой порядок магазинов» виден в режиме правки только при более чем одном уникальном shopId среди текущих привязок, включая ещё не сохранённые. Удаление до одной/нуля привязок скрывает контрол. Сам флаг не сбрасывается, а точки одного магазина не считаются разными привязанными магазинами.

UnitChoices.ranked поднимает подходящие единицы через прежний FuzzySearch, затем добавляет все остальные в исходном ручном порядке. Набор не сужается, даже если ввод не совпадает ни с одной единицей. Ручное новое значение допустимо. Глобальная логика поиска товаров не меняется.

## Окно групп и значок

MultiSelectDialog использует SelectionDialog: явная ширина/ограниченная высота, прокручиваемое тело и отдельная нижняя строка действий. Большой справочник не выталкивает «Отмена»/«Добавить» за пределы окна. Проверяются портрет и низкий landscape. Поведение конкретной клавиатуры на телефоне проверяется отдельно.

Пустой iconKey магазина означает стандартный Store, а не отсутствие изображения. Его пункт в AppearanceSheet теперь называется «Обычный значок магазина»; общий picker других сущностей сохраняет честное «Без значка». Возврат к стандартному виду назван «Вернуть обычный значок». Выбор логотипа/пользовательского значка и fallback при недоступном файле остаются прежними.

## Фон товаров внутри магазина

ShopEntity.purchaseBackground: пустая строка — обычная поверхность карточки, auto — цвет подложки магазина с более сильным смешением, иначе поддерживаемый цвет/HEX. Dropdown «Фон товаров»: обычный / в тон подложки / свой цвет. При auto без подложки используется обычный фон. Предпросмотр и фактический список используют один purchaseCardColor: alpha0.28 для карточки против0.16 для блока. Это даёт чуть более плотный оттенок без потери читаемости. Самостоятельные яркость/контрастность не добавляются.

Оформление действует в группировке покупок по магазинам. Срочность и купленность сохраняют приоритет своих цветов, оформление избранного накладывается на выбранную базу карточки. Виджет не изменяется. Изменения карточки магазина остаются локальными до общей кнопки «Сохранить». Преобразование в рынок переносит поле новым продавцам.

Текстовый обмен отдельными целевыми планами не расширяется оформлением локальных магазинов.
