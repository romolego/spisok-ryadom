## Два разных выбора города

«Город магазина» —поле конкретного профиля. Каждый настоящий город представлен один раз; общий город покупок отмечен вторичной подписью, выбранный для магазина —галочкой. Лишней команды «Текущий город» нет. Город покупок идёт первым, остальные —по алфавиту. Неизвестный выбранный ID не выдаётся за текущий: поле просит выбрать город.

CityField создаёт город через LocationRepository.add(selectAfterCreate=false): запись попадает в общий справочник и выбирается в черновике магазина, но общий город покупок не меняется. Отмена карточки не перемещает магазин. Прежние вызовы add(name) по умолчанию сохраняют поведение создания с переключением общего города.

«Город покупок» —общая настройка приложения. Помимо настроек, CityPicker(compact=true) доступен сверху раздела «Магазины», в том числе при пустом перечне. Выбор записывается прежним active_city; он переключает область покупок/подбора магазинов всего приложения, не создаёт второй независимый фильтр. Значок вопроса объясняет область действия. Переименование/добавление города остаются в общем диалоге. На время массового выделения и перестановки магазинов переключатель выключается, чтобы состав выбранных ID не менялся посреди команды.

ShopListViewModel строит магазины и Venue из одного значения activeCity вместе с полным потоком магазинов. Не смешивать отдельный suspend currentId() с запоздавшим отфильтрованным списком магазинов. Рынки/ТЦ без магазинов тоже остаются видны в своём городе. Переключение города ничего не удаляет.

## Тип и город торгового места

Venue.kind: market / mall / unspecified. Рынок и торговый центр —два явных типа одного контейнера физических точек, независимого от сети бренда. Старые места получают unspecified, никакой эвристики по названию. Редактор позволяет выбрать фактический тип. Преобразование магазина начинается командой «Преобразовать в торговое место», затем выбором рынка/ТЦ и явным подтверждением. Сохраняется прежняя атомарная семантика преобразования с ID физических точек и покупок.

VenueEditorDialog показывает тип и город до названия/общего адреса. Изменение города существующего места подтверждается отдельно. Вложенный редактор из карточки точки показывает город её профиля без отдельного переноса: глобальный перенос выполняется из редактора самого места в перечне магазинов. Общий адрес остаётся полем Venue; label точки не является повторным почтовым адресом.

ShopRepository.updateVenue работает через CatalogueEdits и транзакцию. VenueRelocation переносит только точки этого места. Профиль, все точки которого находятся внутри этого места, сохраняет свой ID и меняет cityId. Если профиль владеет также другими адресами/ТЦ, создаётся профиль того же магазина в новом городе с прежним networkId; остальные точки остаются на месте. Сохраняются ID перемещаемых точек/покупок, количества, отметки, фото и приоритеты; отделы и ссылки товаров отображаются на новый профиль. Ограничения доступности, действующие overrides и прежние порядки точек сохраняются. Если исторический приоритет/отдел ссылается на запрещённую для товара точку, при разделении он не создаёт новую доступность: неактивная подсказка не переносится без ссылки товара на новый профиль. Это отдельно проверено. Проверки владельцев в SQL не выключаются; временное снятие venueId проходит внутри транзакции, при отказе всё откатывается.

Room21→22 добавляет kind с default unspecified. Все предыдущие миграции/схемы сохраняются. Полный ZIP19 записывает тип, ZIP≤18 читается как unspecified; новое поле обязательно для19, неизвестные значения и подмена версии отклоняются до замены базы. Полное восстановление по-прежнему заменяет снимок; не объединяет его.

## Оформление и компактная карточка

Палитра открывает нижнюю модальную панель. У подложки магазина и выделения товаров отдельные checkbox. Выключенные настройки не показывают управление цветом. Выделение товаров при первом включении использует auto/«В тон подложки», также доступен свой цвет; выключение возвращает прежний обычный фон карточек, не меняет данные покупок. Запоминается предыдущий цвет в рамках открытого черновика.

Кликабелен сам показанный символ магазина. ShopSymbolPicker объединяет готовые значки и загрузку своего логотипа. Выбор готового значка снимает логотип; загрузка снимает preset. Обычный значок магазина остаётся Store, пустой iconKey не означает отсутствие картинки. У загруженного логотипа есть явная корзина, подтверждение удаления и возможность замены. Символ и оформление редактируются отдельными локальными черновиками: отмена вложенного выбора не меняет панель, отмена панели не меняет карточку, запись в базу только по Save карточки. Фото точки/места остаются отдельными изображениями и не смешиваются с логотипом магазина.

Тип покупки, короткая заметка и два dropdown срочности находятся в одной карточке без крупного заголовка и без отдельных секций. Параметры/семантика не меняются. Существующие полноэкранные редакторы места сохраняют одинаковые действия Назад/Сохранить вверху; эта итерация не заменяет все диалоги приложения.
