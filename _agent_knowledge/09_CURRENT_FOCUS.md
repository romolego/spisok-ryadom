# 09_CURRENT_FOCUS

Актуально на 17 октября 2026: пользователь поручил автономно довести локальную сборку до практической покупки продуктов. Стабилизация и функции реализованы; текущая итерация завершается регрессионными проверками, APK и инструкцией переноса. Не возвращать работу к этапу «только предложить аудит».

Результаты: города с общим каталогом, единые правила назначения/слияния покупок, нечёткий поиск, многострочный ввод с проверкой/отменой, ZIP v4 и безопасный старый JSON, транзакции и обработка ошибок, ограниченные изображения и ленивые списки. Детали: `01_CURRENT_STATE.md`, `16_IMPLEMENTATION_VERIFICATION.md`.

Работа только на текущем ПК, без GitHub push/PR/merge. Установочный пакет parallel сохраняет старое приложение из-за другого ключа подписи. Новую программу пользователь устанавливает на телефон сам; перенос каталога описан в инструкции поставки.

После установки полезно получить фактический результат прокрутки и покупки на телефоне. Не выдавать JVM/UI-тесты за аппаратный профиль Android. Тестирование QEMU ограничено выключенной виртуализацией и падением software emulator; BIOS и перезагрузка ПК не выполнялись.

Адреса проживания/районы, история, серверная синхронизация и подготовка RuStore не входят в эту локальную поставку. Не создавать дубликаты каталога под каждый город.
