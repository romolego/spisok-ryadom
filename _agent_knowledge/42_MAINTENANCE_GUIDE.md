## Среда и команды

Проект использует Kotlin/Compose, Android Gradle Plugin, KSP и Room. Версии зависимостей — в build.gradle.kts и app/build.gradle.kts. JDK17+, SDK35, minSdk26; Gradle Wrapper8.13. На данном ПК SDK/Gradle/JBR уже настроены в local.properties и tools/verify-local.ps1; эти машинные пути не переносить в код приложения.

```powershell
.\gradlew.bat :app:testStandardDebugUnitTest --console=plain
.\gradlew.bat :app:assembleParallelRelease :app:lintParallelRelease --console=plain
```

Для полного локального прогона можно использовать `tools/verify-local.ps1`. `--offline` допустим только при наличии всех зависимостей в локальном кэше. Один Gradle за раз; не запускать конкурирующие тесты над общими native SQLite ресурсами. В build-файле тесты изолируются `forkEvery=1`, `maxParallelForks=1`, heap768m, чтобы избежать Windows native-finalizer ошибок между sandbox.

Для узкой проверки использовать Test.include конкретных class-файлов через временный init script, а не запускать все75 workers с фильтром, который даст пустые классы. Временные scripts/логи — только .local. Проверка должна подтверждать фактические записи/связи, а не повторять реализацию.

## Как выбирать проверку

| Изменение | Минимально нужные сценарии |
| --- | --- |
| Назначение магазина/точки | AUTO/NONE/EXPLICIT, доступность, город, приоритет, удалённое место, открытая карточка |
| Массовая команда | Несколько ID, общий/несколько магазинов, stale ID, отказ без частичной записи, дедупликация избранного |
| Карточка | Save/Back, autosave on/off, raw recovery, пустое имя, внешняя правка, generation после restore |
| Преднастройка | Общий default, основной магазин, явный recipient/None, мгновенный Save, существующий товар, FK delete |
| Целевой список | Один владелец, showInPurchases без копий, перенос, быстрый/каталожный товар, цена/единица, delete |
| Полная копия | Новый/старый формат, повреждённый ZIP/JSON, неверные типы и ссылки, атомарность, фотографии и настройки |
| Переносимый план | Text/JSON round-trip, количества/единицы/места, заметка/комментарий, preview, неизвестная версия |
| Виджет | Те же строки/отметки, grouping/шрифт/отделы, открытие и добавление; OEM отдельно на телефоне |
| Только документация/публикация | Проверенные исходники/APK по хешам, ссылки, архивы, секреты и повторное скачивание опубликованных файлов |

UI-тесты: искать актуальный элемент меню, учитывать несколько одинаковых подписей и отложенное создание LazyColumn-элементов. Сначала прокрутить родитель к нужному узлу, затем действовать. Не менять продуктовую логику ради упрощения теста. После теста закрывать scenario/ViewModel, дождаться освобождения mutex и только затем закрывать Room.
