# Виджет и очередь массового ввода ·0.33

Прямой запрос8 ноября2026 заменяет механику0.32. В карточке общий IconToggleButton «Скрытие товара в виджете» находится непосредственно слева от палитры, над выбором вариантов; нижний checkbox удалён. isWidgetPrivate по-прежнему общее свойство семейства: оно включает возможность скрытия, не состояние конкретной покупки.

Виджет показывает глазик только у таких товаров. Он меняет shopping_list_entries.widgetHidden текущей покупки через CAS её идентичности/ревизии под барьером восстановления. Таймера нет; показывать/скрывать можно до завершения покупки. Постоянный флаг товара не меняется. Начальное скрытие задаётся WidgetSettings.hidePrivateByDefault (по умолчаниюtrue); новые покупки и копии получают его снимок, слияние количества сохраняет текущее раскрытие. Завершение закрывает раскрытый товар; возврат в некупленное применяет текущий default. При default «открытый» покупка скрытого товара не раскрывает его сама. Нормальные товары никогда не маскируются только из-за поля покупки. Скрыты также количество, accessibility-текст и содержимое Intent.

Покупка фиксируется немедленно. WidgetPurchaseMotion удерживает прежний порядок до180мс после последней быстрой отметки, нативный ViewFlipper перемещает строку вниз с исчезновением за140мс. Следующее нажатие не блокируется, каждая строка уходит за140мс, уже ушедшие строки остаются пустыми до общей пересортировки и не вспыхивают на старом месте. Структурное изменение, другая база или настройки отменяют кадр движения. RemoteViews/лаунчер могут пропустить переход; это не Compose.animateItem и не доказанная плавность OEM.

Дата цены —однострочный свободный текст без помощи о формате и без микрофона; поле той же высоты, что цена.

Bulk: отдельные пакеты в локальной очереди bulk_product_draft.queue. «В очередь» сохраняет даже непроверенный текст без записи покупок. Закрытие сохраняет текущий пакет; открытие другого не теряет текущий ввод. Пакеты/строки удаляются явно; успешный атомарный add удаляет только свой пакет. Пока остались другие пакеты, панель остаётся открытой; после последнего сохраняется прежний возврат в покупки. UUID BulkPurchaseRun предотвращает повтор после прерывания между commit и очисткой очереди; при восстановлении VM завершённые пакеты убираются. Существующий одиночный черновик читается прежним способом. Очередь —локальные незавершённые действия, не история покупок и не новый раздел полного ZIP.

Карточка строки: по центру исходное название, затем подходящие записи каталога; количество рядом только с выбранной записью. Внизу одна пара «Из каталога»/«Создать новый». Общий PurchaseQuantityStepper расширен необязательным редактированием числа; прежние вызовы не изменены. Минус/ввод нуля убирает строку. Совпадение, другой выбор и новый товар дают одинаковый контроль количества. Back из каталога возвращает предпросмотр, затем ввод, затем очередь/закрытие; жест закрытия вызывает сохранение и снимает модальную панель. Прежний confirmValueChange, запрещавший Hidden при onBack, снят только для незаблокированной записи.
