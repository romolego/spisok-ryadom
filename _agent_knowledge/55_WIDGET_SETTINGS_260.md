# Виджет: оформление и купленное ·0.26

Запрос22 октября2026 разрешает изменение виджета, отменяя прежние ограничения «виджет не трогать» для этой итерации. Настройки общие для всех домашних экземпляров, независимы от группировки и скрытия разделов Главной.

WidgetSettings сохраняет прежние mode/showDepartments/textSize и добавляет showBought=true, showBoughtToggle=true, showShopBackground=false, showProductBackground=false. Пустые старые prefs сохраняют прежний список/цвета; появляется новая отключаемая кнопка. Явные подписи группировки: по магазинам, по товарным группам, по получателям, общий список. Группы внутри магазина —его отделы; это отдельный переключатель от товарной классификации.

Кнопка с глазом меняет только widget_show_bought. Покупки не удаляются, не снимаются с Главной и не меняют владельца/listId. Активное скрытие отмечено фоном кнопки и подписью «Купленные скрыты», в пустом состоянии указано отсутствие некупленного. Можно вернуть показ. PendingIntent содержит целевое состояние, поэтому повтор старого скрытия не превращается в обратный toggle. При отключённой кнопке старое действие игнорируется. Для отметки покупки сохранён прежний CAS по ID/UUID/created/updated/bought/revision. Фильтр применяется до построения заголовков, пустые магазины/отделы/ТЦ/группы/получатели не остаются.

Оформление открывается отдельной нижней панелью. Подложки магазинов и товаров независимы. Зоны магазина видны в режиме BY_SHOPS; все точки одного профиля наследуют его сохранённый цвет. Цвет карточки при включении использует сохранённый purchaseBackground (auto/свой), избранное покупки и статусы. Формулы цветов общие с приложением, светлая поверхность виджета сохраняется. Выключение даёт нейтральные карточки; зачёркивание, чекбокс и знак срочности сохраняются при любом фоне. Каждый bind RemoteViews явно задаёт цвет, чтобы recycled view не наследовал чужой фон.

WidgetFrame содержит coherent settings/items/favoriteStyle. SharedPreferences listener обновляет все экземпляры по новым widget-ключам и оформлению избранного; Room invalidation обновляет данные. Узкий layout при options width<260dp оставляет48dp кнопки и короткий заголовок, обычный —прежний заголовок. Настройки размера12–22 сохраняются; примеры/кнопка «обычный размер» не возвращаются.

Room23 без изменений. Полная копияZIP21 включает новые boolean-параметры, строго проверяет их тип до изменения БД; прежние поддерживаемые копии читаются, отсутствующие ключи в восстановленной секции настроек получают совместимые defaults. Ручной импорт для обновления APK не нужен. Личные базы/фото и прежние артефакты не меняются. GitHub текущим запросом не поручен.
