# Массовые операции0.12.0

## Область

Верхний Checklist включает режим выбора в базе товаров, каталоге магазина и списке магазинов. В покупках прежний режим расширен. Отдельные строки и заголовки разделов выбираются checkbox; DoneAll переключает весь текущий набор. «⋮» открывает действия, X/Back отменяют выбор. В режиме выбора обычные кнопки покупки/количества и редактирования порядка скрыты.

Каталог использует productId, магазины — shopId, покупки — entryId. Дубли избранного/нескольких магазинов/адресов не увеличивают счётчик и не повторяют изменения. Смена вида каталога сбрасывает выбор. Поиск/изменение набора удаляют скрытые ID навсегда; простое сворачивание не меняет набор. Выбор раздела включает весь раздел, включая строки ниже viewport. Состояние выбора сохраняется при configuration change, pruning не выполняется до загрузки.

## Действия

Товары: добавить в покупки, назначить/очистить получателя и товарную группу, добавить несколько магазинов, назначить группу магазина, добавить/убрать избранное. Добавление магазина — связь той же карточки, без дублирования товара/покупки и без удаления прежних связей. Из каталога магазина массовое добавление в покупки использует его контекст.

Группа магазина выбирается для общего выбранным товарам магазина. «Все доступные точки» меняет default связи и очищает её point overrides; конкретная общая доступная точка меняет только свой override. Не задано доступно для всего магазина; отдельная точка наследует default при отсутствии override, поэтому UI не предлагает ложное «Без группы» при непустом default. Другая сеть/город/точка/история купленного не изменяются.

Магазины: добавить несколько общих типов групп только выбранным магазинам. Уже существующие local placements переиспользуются; невыбранные магазины не получают новых групп. Это не массовое присвоение группы товарам.

Покупки: купить/вернуть, срочность/снять срочность, перенос некупленных всей выборки через существующий выбор доступных мест/добавление назначения, удалить с подтверждением количества. Смешанная выборка купленных/некупленных позволяет buy/return/delete, срочность и перенос — только полностью некупленной. Количества/ID/заметки сохраняются; удаление покупки сохраняет карточки из постоянной базы. Неиспользуемые разовые temporary-карточки убираются той же политикой, что при одиночном удалении; наличие другой покупки/истории защищает их от очистки.

## Запись

BatchRepository читает свежие строки, проверяет весь набор и записывает в одной Room transaction. Нет update entity из старого UI snapshot. ProductRepository.saveWithLinks сохраняет стабильные links, availability/point priorities и обновляет текущие покупки по прежней общей политике. Добавленные связи разрешают прежнее автоматическое неназначенное место, не переносят допустимую явную покупку.

BatchViewModel сериализует product changes с редактором/restore через ProductEditorTransactions.mutex; ProductDraftStore.applyBatch завершает commit и согласование draft в NonCancellable-секции: закрытие Activity после записи не оставляет старый восстанавливаемый ввод. ProductDraftStore.reconcileBatch меняет только соответствующие поля raw drafts, включая fresh IDs добавленных связей/групп. Добавление связи не переписывает существующие raw настройки этой связи; конкретная группа точки меняет только этот override, сохраняя сырые назначения соседних точек и default. Если точка была исключена сырым ограничением, явное назначение группы включает эту точку в то же подмножество, не удаляя остальные. Неверное сырое количество/незавершённая заметка сохраняются; позднее восстановление не отменяет bulk. Обычные сообщения об ошибке остаются видны, выбор при ошибке не теряется. Busy блокирует повторное выполнение. Room13/ZIP9 не меняются, схема и отдельная база для массовых действий не вводятся.

## Инъекция зависимостей экрана

Изолированный ShopContentScreen не обязан создавать вторую БД или приводить произвольный Application к SpisokRyadomApp. IndependentShopPickerAuditTest передаёт второй VM из той же in-memory базы; прежние физические pointer events, assertions и два SDK сохранены.
