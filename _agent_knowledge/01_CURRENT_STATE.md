## Реализованное поведение

Четыре вкладки: покупки, отдельные списки, каталог, магазины. Покупка имеет одного владельца; включение целевого плана в общий экран не копирует его строки. Есть быстрые временные позиции, каталог, цены плана, общий перенос, текст/JSON обмен целевыми списками, полная резервная копия. Обычный текстовый список — временное сообщение, редактирование которого не меняет корзину.

Места покупки: город, профиль магазина, физические точки, сети и рынки/ТЦ; подписи через общий PlaceLabels. Массовые действия, избранное с повторным представлением в общем каталоге, поиск/голос, создание из запроса, раскрытие сохранённого товара.

В0.17 добавлены общий тип покупки и fallback единицы, правила магазина и получателя группы для новых карточек, 30+30 стандартных категорий, 19 дополнительных значков (всего79). Явный получатель сохраняется, старые товары автоматически не переклассифицируются. Виджет в0.17 не менялся относительно0.16.
