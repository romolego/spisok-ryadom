## Поведение

Из purchase action → «Сменить место покупки» доступен дополнительный путь «Добавить место покупки». Показываются реальные дополнительные места активного города. Можно создать магазин inline. «Добавить и перенести» добавляет отсутствующие links/availability и переносит выбранные pending одной Room-транзакцией. Новая точная привязка отмечает выбранную точку; существующая ограниченная расширяется, остальные адреса/связи не удаляются. Невалидный город/branch owner/исчезнувшая строка отменяет всю команду. Простой CopyProductShop по-прежнему добавляет связь без переноса.

Настройка remember_shop_priority_on_move по умолчаниюfalse. True поднимает магазин и точку у каждого затронутого товара и включает собственный порядок вместо наследования городского. Текущие выбранные покупки переносятся; другие покупки этого товара не двигаются переносом. При следующем AUTO используются сохранённые предпочтения. False не меняет Product/Link priorities/общие Shop/Branch orders.

Карточка товара показывает редактор «Приоритет точек» только при нескольких доступных точках. Общий animated order renderer сохраняет идентичность и обе движущиеся строки. Raw drafts/автосохранение включают этот map. Явное изменение порядка магазина/точек в карточке переопределяет pending в их прежних городах, пересчитывая отдел для нового адреса. Изменение только availability переносит недопустимое назначение; исправляется и прежняя stale строка, не представленная старой связью. Количества/notes/comment/urgency/createdAt/ID сохраняются, bought untouched. Заметка/имя не отменяют допустимое явное место.

ProductCandidateTitle рисует любимую звезду в AddToList, подсказках новой карточки, Bulk matching; в store picker такая же метка. Обычный каталог уже показывал звёзды. Сортировка поиска не изменена.
