# Начать работу с проектом

Основная папка на текущем ПК: `D:\projects\spisok-ryadom`. Здесь находятся актуальный Git-репозиторий, код, документация и локальные материалы. Вторую рабочую копию создавать не нужно.

1. В Codex добавьте локальный проект, выбрав эту папку. Затем перенесите существующий чат в этот проект через боковую панель. Новые чаты запускайте из проекта.
2. Для разработки откройте `AGENTS.md`, затем `_agent_knowledge/11_KNOWLEDGE_ROUTER.md` и `01_CURRENT_STATE.md`.
3. Для понимания устройства приложения прочитайте `_agent_knowledge/41_ARCHITECTURE_ATLAS.md`; для изменений и сборки — `_agent_knowledge/42_MAINTENANCE_GUIDE.md`.
4. Для использования приложения начните с `docs/USER_GUIDE.md`. Последний публичный APK — в GitHub Releases.
