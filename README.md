# Список рядом

Android-приложение для личного списка покупок: база товаров, магазины и физические места покупки, отделы, получатели, избранное и массовые операции. Данные хранятся на устройстве, интернет для работы не нужен.

Текущая версия — **0.12.1 (18)**, Android 8.0+ (API 26), Room 13, формат полной резервной копии ZIP 9.

- [Релиз и APK](https://github.com/romolego/spisok-ryadom/releases/tag/v0.12.1).
- [Итоги аудита и доказательства проверки](docs/releases/0.12.1/README.md).
- [Текущая архитектура](_agent_knowledge/05_APP_STRUCTURE.md), [история решений](_agent_knowledge/08_DECISION_LOG.md) и [последний независимый аудит](_agent_knowledge/33_INDEPENDENT_AUDIT_121.md).

## Что умеет приложение

- Корзина в виде карточек и текстового списка, группировка по магазинам, товарным группам и получателям; отправка списка через системное меню «Поделиться».
- Общая база товаров с поиском, избранным, фотографиями из галереи или камеры и автосохранением карточек.
- Независимые сети, рынки/ТЦ и физические магазины/павильоны; адресные ограничения и приоритеты конкретного товара.
- Перенос покупки с добавлением нового места и необязательным запоминанием приоритета; изменения карточки сразу согласуются с корзиной.
- Массовые действия над покупками, товарами и магазинами; выбор разделов без повторной обработки одного товара.
- Редактируемые справочники, порядок, цвета RGB и набор из 60 значков; анимированные перестановка и сворачивание.
- Домашний виджет с прокруткой и отметками, резервное копирование и восстановление с миграциями прежних форматов.

## Сборка

Нужны JDK 17+, Android SDK Platform 35 и Build Tools 35. Путь SDK задаётся локально через `ANDROID_HOME` или `local.properties` (`sdk.dir=...`). Gradle Wrapper использует Gradle 8.13.

```powershell
.\gradlew.bat :app:testStandardDebugUnitTest :app:assembleParallelRelease :app:lintParallelRelease --console=plain
```

На macOS/Linux используется `./gradlew` с теми же задачами. Интернет нужен для первой загрузки зависимостей. На Windows предпочтителен короткий ASCII-путь `GRADLE_USER_HOME`.

APK появляется в `app/build/outputs/apk/parallel/release/app-parallel-release.apk`. Flavor `parallel` имеет пакет `com.spisokryadom.app.next` и название «Список рядом · новая», поэтому устанавливается рядом со старой программой. Flavor `standard` использует пакет `com.spisokryadom.app`.

Опубликованный APK подписан прежним локальным сертификатом, чтобы обновлять уже выданные сборки `.next`. Ключ не входит в репозиторий. Если `.local/signing/local-development.jks` отсутствует, самостоятельная release-сборка использует debug-ключ текущей машины и не сможет обновить APK с другой подписью.
