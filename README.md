# Список рядом

Android-приложение для регулярных покупок, многоразовых списков: рецептов, событий и проектов. Каталог товаров связан с магазинами, физическими точками, отделами и получателями. Приложение работает с локальной базой Room.

**Локальная версия0.25.0(35), Android8.0+, Room23, полная копияZIP20. Единые списки вместо шаблонов: общий с Главной подбор, живой состав и создание/открытие полноценной карточки товара.**

## Возможности

- Вкладки «Главная», «Списки», «Товары», «Магазины»; регулярные покупки и единые многоразовые списки.
- Общая база товаров, заметный активный фильтр избранного, поиск, создание из запроса, системный голосовой поиск.
- Быстрый выбор показывает уже добавленные товары с текущим количеством; любой список копируется на Главную или в другой список после подтверждения.
- Адреса магазинов, рынки и павильоны, отделы, доступность и приоритеты мест покупки.
- Массовые действия, перенос покупок с добавлением магазина и актуализация назначений.
- Настраиваемое автосохранение карточек, преднастройки новых товаров, цвета и 79 значков.
- Домашний виджет, временное текстовое представление для отправки, обмен целевыми списками и полная резервная копия.
- Стандартная редактируемая библиотека: 30 товарных групп и 30 типов отделов; отделы не добавляются автоматически во все магазины.

## Сборка

JDK 17+, Android SDK 35; Gradle Wrapper 8.13. На Windows:

```powershell
.\gradlew.bat :app:testStandardDebugUnitTest :app:assembleParallelRelease :app:lintParallelRelease --console=plain
```

На рабочем ПК также доступен `tools/verify-local.ps1`. У варианта `parallel` пакет `com.spisokryadom.app.next`, название «Список рядом · новая». Для обновления существующей установки нужна прежняя подпись; оригинальный ключ хранится только локально. Публичный APK уже подписан.
