# Список рядом

«Список рядом» — локальное Android-приложение для ведения постоянного личного списка покупок с собственной базой товаров, магазинами, отделами и локальным хранением данных. Текущая рабочая копия находится на ПК в `D:\projects\spisok-ryadom`. Разработка и данные локальные.

В репозитории есть специальная проектная база знаний для ИИ-агентов: [`_agent_knowledge`](./_agent_knowledge). Она нужна, чтобы любой агент быстро понимал концепцию проекта, текущий этап, обязательные правила, границы первой версии, уже принятые решения и порядок актуализации контекста после каждой правки.

Эта knowledge-база намеренно сделана tool-neutral: ей должны одинаково пользоваться Claude Code, Codex, Cursor и другие ИИ-агенты, работающие с проектом.

Основные смысловые разделы `_agent_knowledge`:
- обзор проекта и текущее состояние;
- пользовательские правила, правила агента и модель итераций;
- каркас приложения, функциональные требования и UI/UX-ограничения;
- журнал проектных решений, текущий фокус и проектные запреты;
- маршрутизатор знаний, протокол актуализации и changelog knowledge-базы;
- контекст первоисточников и границы достоверности.

Точка входа для агента: [`AGENTS.md`](./AGENTS.md) → [`_agent_knowledge/11_KNOWLEDGE_ROUTER.md`](./_agent_knowledge/11_KNOWLEDGE_ROUTER.md) → [`_agent_knowledge/03_AGENT_RULES.md`](./_agent_knowledge/03_AGENT_RULES.md) → профильные файлы по задаче → [`_agent_knowledge/12_UPDATE_PROTOCOL.md`](./_agent_knowledge/12_UPDATE_PROTOCOL.md) перед завершением итерации.


## Текущая версия: 0.2.0

Общий каталог товаров, города магазинов, нечёткий поиск, многострочный ввод с проверкой и отменой, безопасные резервные копии. Текущее состояние: [`01_CURRENT_STATE.md`](_agent_knowledge/01_CURRENT_STATE.md), проверки: [`16_IMPLEMENTATION_VERIFICATION.md`](_agent_knowledge/16_IMPLEMENTATION_VERIFICATION.md).

На этом ПК полный цикл проверки/сборки: `./tools/verify-local.ps1`. На другой машине нужны JDK 17+ (здесь используется JBR 21), Android SDK platform 35/build-tools 35, `local.properties` с sdk.dir; wrapper использует Gradle 8.13. В Windows предпочтителен ASCII-путь GRADLE_USER_HOME.

Готовый APK создаётся в `app/build/outputs/apk/parallel/release/app-parallel-release.apk`. Flavor `parallel` устанавливается рядом со старой программой (`.next`); это необходимо при отсутствии исходного ключа подписи телефона. Для дальнейших обновлений локальный ключ хранится в `.local/signing/local-development.jks`, вне Git. Если ключ отсутствует, Gradle использует debug signing текущей машины — для обновления уже выданного APK нужно восстановить именно сохранённый ключ.

GitHub не обновляется автоматически. Резервные копии пользовательских данных и ключи не коммитить.
