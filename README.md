# Список рядом

Android-приложение для регулярных покупок и отдельных списков. Kotlin, Jetpack Compose, Room; данные хранятся локально. Городские магазины/точки и рынки/ТЦ, избранное, группы, виджет, переносимые списки и полная ZIP-копия.

## Версия0.29.0

[Выпуск0.29.0 опубликован](https://github.com/romolego/spisok-ryadom/releases/tag/v0.29.0).

Общий текстовый ввод с mic/clear, минус в подборе с тем же owner/shop/point scope, до5 фото с порядком/подписями и варианты одного товара. Общие поля семейства синхронны; параметры/фото/магазины независимы, доступность/порядок отдельны по городам. Главная/списки/виджет/копии используют настоящий вариант. Цветовые кнопки магазина единообразны.

Проверка всего набора: 1473/1473 уникальных сценариев в118 классах,54 новых, failures/errors/skipped=0. Все349 файлов source/test/schema/build зафиксированы после окончательной проверки. Release/lint успешны:0 ошибок, 85 предупреждений, 7 подсказок.14 синтетических native PNG API28/35 просмотрены. Изменены4 файла приложения и4 теста, схемы/build прежние. Это не единый полный прогон финального кода; после начала расширенного повтора все349 файлов seal неизменны.
