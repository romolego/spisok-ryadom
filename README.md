# Список покупок

Android-приложение для регулярных покупок и отдельных списков. Kotlin, Jetpack Compose, Room; данные локальные.

## Версия0.33.0

[Скачать APK](https://github.com/romolego/spisok-ryadom/releases/download/v0.33.0/SpisokPokupok-0.33.0.apk) · [Выпуск и файлы](https://github.com/romolego/spisok-ryadom/releases/tag/v0.33.0) · [Квитанция](docs/publications/0.33.0.json).

Глазик в виджете есть только у отмеченных товаров и меняет видимость конкретной покупки, без таймера и смены настройки карточки. Общий переключатель расположен перед палитрой, над вариантами. Начальная видимость настраивается; завершение не раскрывает скрытое имя. Быстрое движение вниз140мс сопровождает одну пересортировку серии, следующая отметка не ждёт перехода. Дата цены —свободный однострочный текст без вопроса.

Массовый ввод хранит очередь отдельных пакетов. Их можно отложить без распознавания, открыть позже, удалить целиком/по строкам и добавить атомарно. Количество через общий плюс/минус и ввод рядом с выбранной записью. Внизу карточки одна пара каталога/создания; Back, жест, close/reopen и черновик сохраняются. После добавления убирается свой пакет; после последнего —прежний возврат к покупкам.
