## Совместимость и ограничения

Room26 и ZIP24 сохранены, новые миграции не требуются. Все прежние схемы, миграции и читатели оставлены. Готовый APK предназначен для установки поверх прежнего приложения `.next` с сохранением базы и настроек: пакет и сертификат совпали с локальным APK0.29.0, versionCode повышен с 39 до 40. Импорт или сброс для обновления не требуется. Фактическая установка поверх приложения на устройстве не выполнялась.

APK: `D:\projects\spisok-ryadom\.local\artifacts\0.29.1\SpisokRyadom-0.29.1.apk` — **0.29.1 (40), 2 185 582 байта**, пакет `com.spisokryadom.app.next`, minSdk26/targetSdk35, `debuggable=false`. `apksigner verify` и `zipalign -c 4` успешны; метаданные проверены через `aapt`.

- SHA256 APK: `5c8a353e1b4d1ca72259c9c32bf14e36e8b96a724306a421f5f928bb01a0430c`.
- SHA256 сертификата: `25617a1a32efbc2acc95aab36a5e108fdaa37ef4bf362025cd39ede92a522668`.
- Прежний APK0.29.0 не изменён: SHA256 `5a1b06c37d2c95b563fdd92dd0909cbd5807f8aea4052178e2d069145ed0ba8c`.

**Физический Android не проверялся и приложение на телефон не устанавливалось.** Подключённых устройств не было. Создан отдельный AVD API35, но аппаратное ускорение недоступно, программный запуск остался `offline`; попытка остановлена без изменения системных настроек. Реальная внешняя галерея/камера, выдача и отказ системных разрешений, голосовой сервис, Gboard, OEM-виджет и OS process kill остаются непроверенными. Robolectric-пересоздание Activity не приравнивается к этим проверкам.

`Audit121UiTest` действительно вызывает `ActivityScenario.recreate()` с сохранением выбора каталога; `Refine090DataTest` пересоздаёт VM и восстанавливает raw-черновик; `GoalImportFileTest` пересоздаёт модель из SavedStateHandle. Landscape-тесты проверяют заранее заданную широкую компоновку, а не поворот работающего устройства. Отдельного прогона физического поворота и обычного ухода в фон/возврата той же Activity не было; эти переходы проверены только аудитом lifecycle-кода и частично пересозданием состояния.

Отдельные пункты без реализации:

- Переносимый список ограничивает составное имя товара с вариантом 500 символами; слишком длинное имя отклоняется с сохранением исходных данных. Полный ZIP сохраняет их. Снятие границы требует отдельного решения по формату, без усечения пользовательского текста.
- Адресат результата внешней галереи после реального уничтожения процесса при открытой дочерней странице варианта требует проверки на Android. По коду есть риск, но воспроизведения нет; предположительный патч не вносился.
- Отменённые временные фото могут оставаться защищёнными от очистки до перезапуска процесса. Это кандидат на необязательное улучшение очистки; потеря пользовательских данных не обнаружена.
- Предупреждения lint и устаревшие визуальные API не устранялись ради косметики или обновления зависимостей.
