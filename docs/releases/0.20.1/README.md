# Список рядом0.20.1 — аудит целостности и очистка кода

Исправлены команды из старых окон после восстановления базы и обработка предельного порядка избранных групп. Убраны остатки отменённого редактирования корзины из текста, старые UI и дублирующие команды. Массовая группа единообразно применяется ко всему магазину; чтение старых исключений сохранено.

Все275 файлов приложения/тестов/схемы/build неизменны после начала полного прогона.

Room18/ZIP14 сохранены, миграция данных для этой очистки не нужна. Виджет и его настройки прежние. Release/lint успешны; точные замечания lint —[verification.json](verification.json).
