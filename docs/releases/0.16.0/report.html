Карточки и поиск ·0.16.0

Список рядом ·19 октября2026

Что изменено

  • Массовая группа. Единственный общий магазин выбран автоматически; при нескольких нужно выбрать магазин. Группа и кнопка «Применить к3» согласованы с этим выбором. Проверена фактическая запись трёх связей и отсутствие изменений другого магазина.
  • Подсказки названия. «Уже в базе» видно только при фокусе поля названия. Открытие группы/получателя, переход к другому полю и IME Done скрывают рекомендации. Возврат к названию снова показывает подходящие товары.
  • Создание из поиска. Явная кнопка «Создать…» открывает карточку с заполненным запросом. Приблизительные совпадения не препятствуют созданию. Точное совпадение проверяется во всём каталоге, включая скрытое фильтром избранного. После Save карточка раскрывается и показывается в каталоге; покупка не создаётся автоматически.
  • Голосовой поиск. Микрофон доступен в поиске каталога, каталога магазина и подборе из базы целевого списка. Успех меняет только запрос; отмена сохраняет прежний запрос. Если обработчик не установлен, показано понятное сообщение. На телефоне фактическое распознавание не проверялось.
  • Настройка автосохранения. Настройки → Поведение списка → Автосохранение карточек товаров. По умолчанию включено, как раньше. При выключении карточка записывается только кнопкой «Сохранить»; Back и уход из редактора отбрасывают незаписанные правки. Такие черновики не восстанавливаются при старте. Настройка переносится в полной копии.
  • Очищенное название. Новый автоматически созданный товар без покупок убирается из каталога после очистки названия, остальные незавершённые поля остаются в безымянном черновике. У существующего или уже используемого товара пустое имя требует исправления; обычный выход остаётся в редакторе с ошибкой. Покупки не удаляются.
  • Совместимость. Room15/ZIP11 и прежняя подпись сохранены; виджет и его настройки не менялись. Автосохранение позиций целевых списков сохраняет прежний режим. Личная база и прежние APK не изменены.
