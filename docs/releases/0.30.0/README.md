7 ноября2026. Согласованные доработки реализованы с прежними компонентами и навигацией. Код `fe08d73738808e7481c12f4ec5d1b645c6547688`, исходный чистый main `0cfa0c94790e66a6681ba7339bbb01244b632b02`, ветка `codex/product-prefill-bulk-0.30.0`. Новая публикация GitHub не выполнялась.

## Что изменилось

- Скрытые283 русских товара/386 имён и алиасов,26 секций; подсказки категории, единицы и общей группы. Позиции словаря не появляются в каталоге или поиске. Ручной выбор/очистка первичны, сомнительные совпадения не угадываются. Покупательские единицы: бананы вшт, гречка/спагетти вупак.
- Общая группа товара задаётся до магазина и наследуется новыми привязками. Недостающее размещение создаётся при сохранении. Старые локальные группы/исключения/маршруты остаются; автоматика отключается. Общий получатель включается отдельно и уступает явному выбору/правилу категории. Mic убран только из единицы карточки.
- Массовый ввод регулярных покупок: запятая, точка с запятой, перенос строки и **любая точка** разделяют названия. Количество/единицы из текста не парсятся. В предпросмотре видны исходное имя и выбор; можно выбрать похожий реальный вариант, создать новый, исправить количество1 и убрать строку. Запись только через «Добавить все», одной транзакцией и без повторного применения UUID. Отдельные списки используют прежний подбор.
- Фото открывается для pinch/pan/двойного нажатия; карандаш сохраняет прежнее редактирование/удаление/порядок. Ссылка открывается нажатием, редактируется карандашом; URL выделяется из скопированного текста, из нескольких можно выбрать нужный.
