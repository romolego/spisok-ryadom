Что изменилось

  • Настройки → Поведение списка. Подписи переключателей компактнее внутри строк и отделены друг от друга.
  • Добавить покупку. До ввода видны товары выбранного магазина/адреса. При автоматическом выборе — весь каталог. Избранные отдельно сверху и повторно на своём месте в полном алфавите, со звёздочкой. Поиск сохраняет порядок совпадений.
  • Несколько покупок подряд. Кнопка корзины у строки добавляет количество по умолчанию и оставляет экран открытым. Нажатие строки позволяет изменить количество перед добавлением.
  • Отключение предварительного списка. Настройки → Поведение списка → «Показывать товары до ввода названия». Поиск и создание новых товаров работают при любом положении переключателя.
  • Текстовый список. Открывается кнопкой в заголовке корзины, предназначен для чтения и отправки. Правки временные, не меняют покупки. При закрытии и новом открытии текст формируется заново. «Поделиться» отправляет видимый отредактированный текст. Долгий плюс больше не открывает меню.

Виджет и его настройки сохранены без изменений.
