# Выпуски и проверки

- [0.13.0](0.13.0/README.md) — Настройки группировки и текста виджета, иерархия заголовков и подложка магазина. 537 проверок.
- [0.14.0](0.14.0/README.md) — Выбор товара до ввода, избранное в списке выбора, временный текст для отправки. 563 проверок.
- [0.15.0](0.15.0/README.md) — Целевые списки, быстрые позиции, цены и обмен текстом/JSON; единый владелец покупок. 704 проверок.
- [0.15.1](0.15.1/README.md) — Независимый аудит целевых списков, атомарность правок/переносов, цены и обмен. 798 проверок.
- [0.16.0](0.16.0/README.md) — Массовая группа, фокус подсказок, создание из поиска, голос и настройка автосохранения. 844 проверок.
- [0.17.0](0.17.0/README.md) — Преднастройки магазина/получателя, fallback единицы, библиотека30+30 и79 значков. 898 проверок.

Предыдущая опубликованная версия: [0.12.1](0.12.1/README.md). Публичные файлы очищены отдельно; исходные локальные доказательства не заменены.
