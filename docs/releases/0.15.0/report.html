Список рядом · 0.15.0

Целевые списки для рецептов, событий и проектов · 19 октября2026

Как пользоваться

  1. Откройте вкладку «Списки» и нажмите плюс. Первая карточка «Текущие покупки» ведёт в прежнюю корзину.
  2. Добавляйте быстрые позиции без магазина или выбирайте из общей базы. Количество, единица, место, заметка и цена за единицу необязательны, кроме названия/положительного количества. Валидный ввод сохраняется автоматически.
  3. В настройках списка включите «Отображать в покупках», если план нужен в общей корзине. Отметки и количества общие: это те же позиции, без копий.
  4. «Поделиться» открывает текст для мессенджера; меню списка позволяет экспортировать JSON-файл. Редактирование сообщения не меняет сам список.
  5. Получатель открывает «Списки» → импорт и вставляет сообщение либо выбирает файл. После предпросмотра создаётся отдельный новый список. Отметки покупки сброшены, срочность и плановые данные сохранены.

Данные и совместимость

Регулярная корзина сохраняется. Новый список по умолчанию скрыт из неё. Перенос между списками сохраняет количество, цену и отметки. Цены ориентировочные, за единицу; итог не включает строки без цены. Незнакомое место из сообщения остаётся текстом, без автоматического создания магазинов или слияния каталога. Полная резервная копия включает все списки, скрытые строки и их состояния.

Обновление0.14.0 →0.15.0 использует Room14→15 без удаления данных. ZIP11 читает прежние копии. Внешний вид и настройки виджета сохранены. Экран текста основной корзины остаётся только сообщением для отправки.
