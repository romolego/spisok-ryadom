# Список рядом 0.23.0

Точки магазина можно переставить в любом порядке, включая только что добавленные. Рынок или ТЦ владеет одним общим почтовым адресом; павильон/этаж/вход хранится отдельно. Выбор ТЦ сразу показывает его адрес, изменение отражается у всех связанных продавцов. Неизвестный адрес остаётся неизвестным; название павильона больше не подставляется вместо него.

Точка и ТЦ используют общий полноэкранный редактор с фиксированными действиями вверху. Фото рынка/ТЦ хранится один раз, фото точки независимо; управление иконками, удаление с подтверждением. При редактировании внутри карточки магазина вложенные изменения фиксируются её общей транзакцией. Старые inline-редактор Venue, venueNames и неиспользуемый BranchAvailabilityEditor удалены.
