## Изменения

- В редактируемых текстовых полях микрофон сменяется крестиком очистки. Голос заполняет черновик, отмена распознавания его сохраняет. Числа очищаются без голосового ввода; списки выбора сохраняют стрелки.
- В подборе есть минус, последнее уменьшение удаляет позицию. Метка и действие используют один список/магазин/точку; уменьшается последняя изменённая строка этого товара или его варианта.
- До5 фото каждого варианта: горизонтальный ряд, подписи и порядок, первая основная. Удаление подтверждается; очистка файлов учитывает все фото несохранённого черновика.
- Единая карточка товара с вариантами. Общие имя/группа/получатель/избранность/акцент; собственные параметры, фото, цены и магазины. Варианты переключаются свайпом или стрелками, закупка хранит конкретный вариант.
- Доступность и приоритет вариантов отдельны по городам. Правки нескольких городов сохраняются атомарно, при переключении города черновик не теряется. По желанию выбранный вариант запоминается первым в текущем городе.
- Главная, отдельные списки, копирование, виджет и ZIP работают с настоящими вариантами; в каталоге остаётся одна строка на товар. Старые ID/покупки/миграции сохранены.
- Подложка и выделение товаров магазина используют одинаковые цветовые кнопки. В общей панели цвета — переключатель «В тон подложки» и собственная палитра.

## Границы проверки

Native Robolectric, API28/35 там, где указано в Config. Физический телефон, настоящий сервис распознавания, Gboard, OEM-хост виджета и внешняя галерея не проверены. Намерения запуска/отмена камеры и голоса, реальные Room-транзакции, миграции, фотографии и ZIP проверены локальным стендом.

Основной вариант сохраняет исходную идентичность товара; отдельно удаляются дополнительные варианты. Разовая позиция должна быть явно сохранена в каталоге перед созданием вариантов. Создание/удаление варианта и применение его городских приоритетов — отдельные подтверждённые действия; Back карточки их не откатывает. Импорт полной базы заменяет её, переносимый список — отдельный протокол.

Публичный JUnit содержит только имена, длительности и статусы. Личные базы/фото/ключи и служебные потоки JUnit не публикуются.
