# Список покупок0.32.0 ·исправления пользовательских сценариев

Прямые замечания пользователя заменяют прежние таймер раскрытия и анимацию виджета. Базовый чистый1bf68d7 сохранён вmain, работа —codex/usability-corrections-0.32.0. Код `c8bd15995dbb7f134d1b3352a204b9df249515dc`.

## Изменения

- Пояснения открываются только через вопрос рядом с полем; правило закреплено в02/07/AGENTS. Постоянные тексты виджета и bulk убраны. Цена/дата не имеют микрофона, многострочные действия находятся справа вверху.
- Глазик виджета сохраняет видимость товара/семейства в isWidgetPrivate, общую для всех виджетов и карточки. Таймера нет. Отметка покупки и порядок обновляются без fade/задержки, прежние CAS и защита DatabaseRevision сохраняются. Приватность внизу карточки.
- Пустая ссылка —подпись и плюс; сохранённая —URL для перехода и карандаш. В редакторе кнопка clipboard, URL из всего текста и выбор из нескольких. Под полем нет дубликата URL.
- Просмотр фото закрывается крестиком справа; масштаб меняется жестами. Галерея магазина до5 фото, порядок/основное/подписи и увеличение; логотип и фотографии точек независимы.
- Bulk показывает подходящие товары и создание непосредственно в строке. Новый товар можно переименовать, количество изменить, строку убрать. Другой поиск доступен отдельно. Back возвращает выбор→предпросмотр→исходный текст с сохранёнными решениями. Закрытие подтверждается, черновик хранится локально. Пакет записывается транзакционно с прежней защитой повторов.
