## Изменения

Приватность выбранного товара только в виджете: маска названия/количества, раскрытие нажатием на5с и раннее скрытие повторным нажатием; отдельная галочка покупки. Настройка общая для вариантов. Перед пересортировкой купленного —native fade/короткое смещение260мс, запись покупки немедленная прежним CAS. Остальной интерфейс, функции и данные сохранены.

В скрытых RemoteViews нет настоящего названия/количества, включая дочерние TextView, accessibility и Intent. Заголовки магазинов/отделов/получателей прежние. Приватные строки остаются на месте; в приложении товар виден как раньше. Контракт —[62](../../../_agent_knowledge/62_WIDGET_PRIVACY_310.md).

Текущий виджет остаётся RemoteViews/ListView. ViewFlipper и анимация переключения —[штатные Android-средства](https://developer.android.com/reference/android/widget/RemoteViews); Android реализует запуск in/out animation при [setDisplayedChild/showOnly](https://android.googlesource.com/platform/frameworks/base/+/master/core/java/android/widget/ViewAnimator.java). Реализация использует исчезновение перед переносом; плавное перемещение всего списка Compose сюда не перенесено. Видимость промежуточной фазы зависит от хоста —это ограничение реализации, требующее проверки на конкретном лаунчере.
