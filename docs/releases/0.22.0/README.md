# Список рядом0.22.0

Свой порядок магазинов скрыт при0/1 привязке. Подбор единиц ранжирует совпадения, сохраняя остальные варианты. Сеть и независимые ТЦ точек сохраняются в одном профиле: сводка и выбор адресов показывают принадлежность, секции магазина используют общий PlaceLabels. Пустой значок магазина назван обычным. В окне групп прокручивается тело, действия остаются внизу. Новый фон карточек магазина: обычный, в тон подложки или свой цвет; предпросмотр и покупки используют один renderer.

231/231 сценарий в16 затронутых классах прошёл в расширенном наборе и повторе UI-класса после упрощения заголовка сети, включая25 новых. Новые сценарииAPI28/35; низкий landscape дополнительноAPI35. Проверены смешанная сеть/ТЦ/улица, удаления/назначения, реактивный фон и подписи, новые/старые backup, повреждённые входы, миграции1→19 и сохранность данных, работа карточек и окон выбора. Это адресная регрессия, не полный повтор набора0.20.1.7 native PNG; физический телефон и конкретная клавиатура отдельно не проверялись.

После основного набора изменена только краткая подпись сети в ShopCardBlocks; все9 проверок соответствующего UI-класса повторены. После итоговой фиксации286 source/test/schema/build файлов приложение не менялось; release/lint завершены успешно. Пакет и сертификат прежние; русский label/версия/подпись/SHA256 проверены.
