Главная показывает регулярные покупки и включённые строки отдельных списков без копирования. Копирование списка —отдельная атомарная команда с независимыми строками. Каталожные счётчики намеренно меняют регулярные покупки; они не должны незаметно редактировать позиции целевых списков.

У переносимого текста/JSON сохраняются отдельные границы: до1000 позиций и1МиБ документа. Проверка полей при записи не снимает этот лимит всего документа и не вводит новый глобальный предел размера базы. Большой список остаётся в приложении и полной резервной копии; переносимый экспорт такого документа отклоняется с сообщением о превышении формата.

Единообразие учитывает назначение окна: короткий выбор/настройка —нижняя панель; подтверждение удаления, ошибка и справка —стандартный диалог; адрес/город/фото места —полноэкранный редактор. Это сохраняет один понятный контракт сохранения для каждого вида действия.

Полный набор включает прежние тесты регулярных покупок, каталога, массовых операций, мест/городов/сетей, доступности и приоритетов, черновиков, справочников/сброса, списков, текстового обмена, резервных копий и виджета. После начала этого набора изменены7 файлов: общий компонент raw-ввода и6 тестовых файлов с сохранением прежних содержательных assertions. Для повторения выбраны26 целых классов:290 прежних сценариев и2 новых, всего292. Повтор завершён: 292 проверок в 26 классах, failures/errors/skipped=0. Уникальное итоговое объединение содержит 1361 сценарий в 112 классах, failures/errors/skipped=0. Повторённый класс заменяется целиком, случаи не удаляются и не складываются дважды. Это полный набор с адресной перепроверкой, а не один полный успешный запуск на окончательном коде.

Первая попытка повтора остановилась на compileUnitTest из-за двух цепочек после Unit-возвращающего performTextReplacement в новом тесте. Исправление затронуло только уже перечисленный Audit270UiTest; тестовые сценарии этой попыткой не исполнялись и в итоговые числа не добавляются. Compile-only проверка также не заменяет повтор26 классов. Предварительные прерванные попытки и исправление блокирующего ожидания paused looper сохранены локально отдельно от итогового recheck.log.

Предупреждения lint рассмотрены отдельно от тестов. Context в Batch/Settings создаётся production-фабриками из Application; подпись кнопки отметки виджета задаётся динамически в RemoteViews. Синхронные commit сохраняют контракт черновика/восстановления; атрибуты виджета API31 дополняют совместимые старые размеры. Остальные замечания относятся к рекомендациям KTX/Compose, ресурсам и версиям зависимостей; массовое обновление библиотек в этот аудит не включено. Точные количества предупреждений и подсказок приведены в verification.json.

Проверка native Robolectric на API28/35 и просмотр PNG не заменяют физический телефон, реальную клавиатуру/голосовой провайдер или OEM-лаунчер виджета. Личные базы, фотографии, ключ подписи и сырые системные логи в публичный комплект не включены. При обычном обновлении APK база мигрирует автоматически; повторный импорт старой копии для обновления не нужен.
