## Изменения

- Настройки виджета в одной нижней панели; размер12–22 через список. Четыре справочника открываются по запросу; сброс в самом низу.
- Звёздочка вместо checkbox в карточках; у товара в той же строке галерея/камера/палитра, фото ниже. Формат покупки до количества, доступен смешанный вариант.
- Для единственной точки скрыты выбор доступности и приоритеты.
- Город покупок только в настройках. Карточка магазина хранит отдельные адреса городов, отмена не сохраняет, Save атомарный. Общий черновик отделов/имени сети не откатывается при переходах между городами.
- Новые городские адреса явно наследуют каталог данного магазина; совпадение старых имён не объединяет записи. Городской автоподбор не использует чужие магазины; товары сохраняются.
- Массовые настройки магазинов через карандаш: отделы, избранность, формат покупки, два параметра срочности. Активное избранное обозначено в заголовках товаров/магазинов.

## Ограничения и методика

Низкоуровневое восстановление города не меняет снимок покупок; пользовательская смена города переназначает только регулярные некупленные автоматические строки. Купленные, отдельные списки, явное «Без магазина» и свободные места сохраняются. Физический перенос ТЦ в город с уже существующим профилем того же магазина отклоняется до записи; автоматического объединения профилей нет.

Предварительные попытки с исправлениями UI-стенда не включены в494. Старые миграции и схемы сохранены, пакет и подпись прежние. Публичный JUnit содержит только разрешённые имена/время/статусы; личные базы, фото и ключи не публикуются.
