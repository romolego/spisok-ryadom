# Постоянная папка проекта на этом ПК

Основная папка: **D:\projects\spisok-ryadom**. Она уже содержит репозиторий, весь актуальный локальный код0.20, Android-проект и базу знаний. Работа больше не должна начинаться из папки случайного чата.

## Подключение к Codex

Добавьте локальный проект и выберите указанную папку. В боковой панели перенесите в него этот существующий чат. Новые чаты создавайте внутри проекта, чтобы основной рабочей папкой и источником AGENTS был корень репозитория. Регистрация проекта и перенос чата не требуют копирования исходников.

Официальная справка о папках и проектах: https://learn.chatgpt.com/docs/projects. Дополнительные папки и основной cwd задаются настройками проекта; внутренние БД/настройки Codex вручную не редактировались.

## Размещение файлов

`START_HERE.md` — короткий вход. `README.md` — возможности и публичный релиз. `_agent_knowledge/01_CURRENT_STATE.md` — действующая версия и подтверждённые факты. `41_ARCHITECTURE_ATLAS.md` — устройство и причины решений. `42_MAINTENANCE_GUIDE.md` — изменения/сборка/проверка. История требований и аудитов сохранена в этой же базе.

`.local/artifacts/` содержит копию всех ранее выданных файлов. `.local/refine200/` — текущая проверка0.20; `.local/refine190/` — сохранённая проверка0.19; `.local/verification/0.17.0/` — доказательства опубликованного0.17; `.local/private/backups/` — исходная и преобразованная личная база19 октября. `.local/signing/` содержит прежний ключ. Эти материалы не входят в Git.

Исходная папка чата `%USERPROFILE%\Documents\Codex\2026-10-16\new-chat` и исходный Downloads ZIP сохранены. Копии проверяются по SHA256. Локальная публикация также сохраняет очищенный публичный комплект рядом с исходными результатами.

Для IDE откройте эту же папку в Android Studio. Машинные SDK/кэш — local.properties и переменные окружения; не публикуйте их. Для нового ПК клонируйте GitHub и настройте собственный SDK; для совместимой подписи готового установленного приложения нужен исходный локальный ключ.
